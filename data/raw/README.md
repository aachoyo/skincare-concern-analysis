# Raw data

`cosmetics.csv` — the original Kaggle dataset (~1,400 Sephora skincare products:
brand, name, price, rating, category, ingredient list, skin-type flags).

Not committed here. Download from Kaggle ("Cosmetics datasets" / Sephora skincare)
and drop `cosmetics.csv` into this folder before running `src/data_cleanup.py`.
Check the dataset's license before redistributing it.
